# مركز المجد للعلاج الطبيعي والتأهيل

موقع مركز المجد للعلاج الطبيعي والتأهيل، مبني باستخدام React وVite.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## التحقق والبناء

```bash
npm run lint
npm run build
```

## الأرشفة ومحركات البحث

الدومين الأساسي: https://almajdphysicaltherapy.online/

بعد نشر التعديلات، أضف الرابط التالي في Google Search Console ← ملفات خرائط الموقع:

https://almajdphysicaltherapy.online/sitemap.xml

ملف تعليمات الزحف: https://almajdphysicaltherapy.online/robots.txt

الموقع صفحة واحدة؛ أقسامه ذات الروابط `#` ليست صفحات مستقلة في خريطة الموقع.
عند إضافة صفحات مستقلة، أضف روابطها الأساسية إلى `Public/sitemap.xml`.
بعد النشر، افحص رابط الصفحة الرئيسية في Search Console واطلب الفهرسة.
تقديم خريطة الموقع لا يضمن الفهرسة أو ترتيباً معيناً في البحث.
